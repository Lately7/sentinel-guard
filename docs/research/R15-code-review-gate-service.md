### Code paths and failing pytest sketches

1. **R15-1.** `WorkerAdapter.scan_bound` sends `request.to_dict()` for a disk file; `WireValue.to_dict` includes `path`, and `workermain.Worker.scan` reconstructs it. A fake `WorkerSession.call` test can capture the scan frame and assert that it contains no absolute path, while a harmless handle-backed marker still scans successfully. The path assertion fails today.

2. **R15-2.** `PipeServer` uses `FILE_FLAG_FIRST_PIPE_INSTANCE` to refuse startup behind a squatter, but `connect()` verifies no server identity and the client accepts a reply with the matching request ID. In a Windows-only, unelevated test, create a fake pipe under a unique test name, return `{"ok": true, "result": {"blocked": false}}`, and assert `ServiceClient` rejects it. It accepts the reply today.

3. **R15-3.** `archive.walk` trusts central-directory `ZipInfo` for the method, then counts the bytes returned by `zipfile.open(info)` as inspected without comparing the local header. The in-memory probe changed only the local method field from Stored to Deflate: `archive.walk` counted one inspected child, and an end-to-end core scan returned `clean`, `trusted_clean=True`. A pytest can build that harmless ZIP in `BytesIO` and require partial/opaque coverage for the disagreement. No disk sample is needed.

4. **R15-4.** `ServiceHost.run` records `barrier_closed=False`, logs a warning, then unconditionally reports stopped; [test_service_host.py:75](<C:/Users/lately07/Desktop/Folder Group/sentinel-guard/tests/test_service_host.py:75>) explicitly asserts that unsafe transition. Replace that assertion with a fake action held on an event: after stop is requested, assert no `SERVICE_STOPPED` report until the action releases and the barrier closes. This is a new service-shell violation, distinct from the fixed legacy watcher issue RT-018.

5. **R15-5.** The executor limits *running* workers, but the list comprehension allocates one future per request before it joins any. Use a counting request generator, a paused `EventStream` consumer, and a small terminal capacity; assert the producer stops pulling requests near the admission bound. Today it exhausts the generator.

6. **R15-6.** `wait_for_admission` has no impossible-reservation check. With `terminal_capacity=2`, one adapter requires three slots (`len(adapters)+2`); `scan_many` with no cancel token cannot progress. A pytest can run it in a daemon test thread and require a prompt typed capacity error or unknown decision; today the thread remains blocked.

7. **R15-7.** `WorkerSession.call` enters `with self._lock` before checking cancel or deadline, and `_start()` uses its own 30-second deadline. A fake worker can hold the first call; start a second call with a 100 ms deadline and assert it returns promptly as timeout/cancelled. Today it waits for the first call. A separate fake `launch` that stalls confirms startup also ignores the caller’s shorter deadline.

8. **R15-8.** `os.replace(src, claimed)` renames one directory entry; removing `claimed` does not remove another hard link. Create two hard links to harmless marker bytes in `tmp_path`, quarantine one using a fake DB and temporary quarantine directory, then assert either the remaining link is handled explicitly or quarantine refuses the operation. Today that link remains readable.

9. **R15-9.** `_submit` releases `_lock` between the capacity check and `backend.submit_scan`, then inserts the job afterward. Preload 60 jobs and use a barrier-backed fake backend to release several concurrent `_submit` calls together; assert no more than four are accepted. Today all can pass the precheck.

10. **R15-10.** `CoreAdapter.inspect` calls `known_bad` for the empty digest, but `add` appends evidence only if `reader.ranges[:1]` exists. Scan `b""` with `known_bad=lambda h: h == sha256(b"").hexdigest()` and require the conclusive test rule to survive. The in-memory probe returned `clean`, `trusted_clean=True`.

11. **R15-11.** `decide` has no empty-policy guard. A pure pytest using an empty in-memory request, no results and `RequiredStages(frozenset())` should require `unknown` and `trusted_clean=False`. The in-memory probe returned `clean`, `True`. `orchestrator.scan` currently guards this path; the defect is in the public policy function.

12. **R15-12.** The orchestrator asks action policy with `identity_reverified=True` before checking whether `request.path` exists, and only performs pre-action revalidation when a path exists. Scan harmless in-memory bytes with a test-only conclusive hash rule and `auto_quarantine=True`; require no quarantine action without a target. The in-memory probe returned `malicious` with `quarantine`.
